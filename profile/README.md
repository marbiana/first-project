# Марина Орлова

Развиваюсь в аналитике данных и инженерии данных, опираясь на практический опыт работы с Wildberries.

Занимаюсь задачами финансовой отчётности, управления запасами и автоматизации расчётов.
Понимаю бизнес-смысл данных маркетплейса и перевод этих правил в Python и SQL.

## Основные навыки

- Python, pandas, SQL и PostgreSQL.
- Загрузка, преобразование и проверка данных.
- Финансовая аналитика и расчёт потребности в поставках.
- Учебные проекты на Airflow, PySpark, Kafka и Docker.
