# Wildberries Finance Analytics

> Шаблон описания будущей публичной версии. Актуальный код и демонстрация ещё не перенесены. Наличие перечисленных возможностей нужно подтвердить при сборке проекта.

## Задача

Подготовить финансовые отчёты Wildberries для анализа продаж, возвратов, удержаний и сумм к перечислению. Дать возможность проследить показатель от итогового отчёта до исходной операции.

## Демонстрация результата

Здесь разместить скриншот отчёта на синтетических данных и ссылку на итоговый пример.
В подписи указать период, единицы измерения и статус данных: demo.

## Что реализовано мной

После проверки перечислить собственные компоненты: загрузчик, преобразования, SQL-витрины, расчёты, отчёт.
Отдельно указать сторонние библиотеки и используемые шаблоны.

## Источники и схема обработки

Указать фактический источник: API WB или выгрузка файлов, формат, версию, дату проверки и период.
Предлагаемый путь: источник → raw/staging → нормализация → витрины → отчёт.
Описать ключ исходной строки и правила повторной загрузки; не обещать отсутствие дублей без проверки.

## Метрики

Для каждой метрики указать:
1. исходные поля;
2. знаки продаж, возвратов и корректировок;
3. период и уровень детализации;
4. расходы, которые входят и не входят в расчёт;
5. контрольный пример.

Если нет себестоимости, налогов и всех расходов, не называть остаток после удержаний чистой прибылью.
Комиссию и логистику считать по подтверждённым операциям, не по одному универсальному проценту.

## Запуск

Добавить реальные команды установки, запуска demo и рабочего режима после проверки кода.
Demo должен работать без аккаунта WB, без токена и без обращения к API.
Рабочий режим должен получать секреты из настроек окружения.

## Проверки при сборке

- Повторная загрузка одного отчёта не меняет результат.
- Контрольные суммы совпадают с подготовленным источником.
- Продажи, возвраты и корректировки учтены с правильными знаками.
- Неизвестные операции видны в отчёте качества.
- Отсутствие значения отличается от нуля.
- Суммы по витринам сверяются с детализацией.

## Результат и ограничения

Указать только измеренные эффекты: время обработки, объём строк, ручные операции, которые удалось убрать.
Описать недостающие расходы, поддерживаемые форматы и ограничения источника.
