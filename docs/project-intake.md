# Материалы для переноса рабочих проектов

## Для каждого из двух проектов

1. ZIP актуальной папки проекта или ссылка на репозиторий с рабочей версией.
2. Короткое указание, какой файл запускается и какие результаты создаёт.
3. Небольшой обезличенный или синтетический пример входа.
4. Пример итогового Excel/отчёта и, если есть, скриншот дашборда.
5. Основные бизнес-правила и известные ошибки.
6. Файл зависимостей и инструкция запуска, если уже есть.

Рабочие токены, пароли, файлы .env и реальные финансовые выгрузки не нужны.

## Для финансового проекта

- Источник данных: API или файлы.
- Поддерживаемые виды отчётов и операций.
- Какие метрики уже считаются и какие расходы доступны.
- Как выполняется повторная загрузка.
- Один пример сверки исходной суммы с результатом.

## Для калькулятора

- Какая версия используется сейчас.
- Горизонт запаса и период истории.
- Заказы или продажи используются в среднем.
- Правила товаров в пути, собственного склада, коробок и паллет.
- Один товар с ручным контрольным расчётом.

## Для профиля

- Приоритет: Data Analyst или Data Engineer.
- Публичный контакт: выбранная почта, Telegram или ссылка на резюме.
- Подтверждённые результаты проектов, если есть замеры.
- Что можно публиковать из рабочего кода.
